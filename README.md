 Superstore Sales Analysis | End-to-End Data Analytics Project

##  Project Overview

This project is an end-to-end data analytics case study using the Sample Superstore dataset. The objective was to analyze sales performance, customer behavior, regional trends, and profitability using SQL, Python, and Power BI.

The project follows the complete data analytics workflow—from querying raw data in SQL to cleaning and analyzing it in Python, and finally building an interactive dashboard in Power BI.



#  Objectives

* Analyze overall sales and profit performance.
* Identify high-performing product categories and regions.
* Understand customer purchasing patterns.
* Perform exploratory data analysis (EDA).
* Build an interactive Power BI dashboard for business decision-making.
